# about-kimbap
This is my project about kimbap.

what it is: An informational page about Korean kimbap, along with an ingredient list and recipe. 

How I made it:
I used html and CSS to build my webpage and google as another resource for accurate research.

Some of the challenges:
I had to do some research on how to change the smoothness of the edges on images. And I had to figure out how to center the bullet points and numbers with the rest of the text.

What I learned: I learned a few new html and CSS tags to use for future projects.
